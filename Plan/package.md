# Packages Overview

## Root
- concurrently: run Frontend and Backend together during development
- prettier: code formatting

## Backend
- express: HTTP server
- cors: enable cross-origin requests from Frontend
- helmet: common HTTP security headers
- cookie-parser: parse httpOnly JWT cookies
- dotenv: load environment variables
- bcrypt: password hashing to avoid plaintext storage
- jsonwebtoken: JWT creation/verification
- zod: input validation
- multer: handle multipart/form-data uploads
- xlsx: parse `.csv`/`.xlsx` vocabulary files
- prisma + @prisma/client: ORM with SQLite
- typescript, ts-node-dev and @types/*: TypeScript tooling

## Frontend
- react, react-dom: UI
- vite: dev server and build
- typescript: type safety
- react-router-dom: client routing
- axios: HTTP client with credentials
- @mui/material, @mui/icons-material: UI components
